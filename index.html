Apprends Linux et Python facilement

Étape 1 — Créer la clé USB

Télécharge Ubuntu sur ubuntu.com puis ouvre le Créateur de disque de démarrage dans les applications.

Sélectionne le fichier ISO téléchargé, sélectionne ta clé USB et clique sur Créer le disque de démarrage. Attends 10-15 minutes.

Étape 2 — Démarrer sur la clé

Branche la clé USB sur le PC cible. Allume le PC et appuie rapidement sur F2 pour accéder au BIOS.

Va dans Boot, désactive le Secure Boot dans Security, sauvegarde avec F10 et redémarre. Le menu Ubuntu apparaît !

Étape 3 — Installer Ubuntu

Clique sur Install Ubuntu, choisis Interactive Installation, puis Default, coche les deux cases de logiciels, choisis Erase disk et suis les étapes.

L'installation dure environ 15-20 minutes. Le PC redémarre tout seul à la fin !

🐍 C'est quoi Python ?

Python est un langage de programmation simple et puissant. C'est le langage numéro 1 pour débuter, utilisé par les hackers, les développeurs IA et les ingénieurs.

Leçon 1 — Afficher du texte

La commande print() affiche du texte à l'écran.

print("Bonjour !")

Résultat : Bonjour !

Leçon 2 — Les variables

Une variable c'est une boîte qui stocke une valeur.

nom = "Cylian" age = 15 print("Je m'appelle", nom, "et j'ai", age, "ans")

Leçon 3 — Les conditions

Le if/else permet de faire des choix dans le code.

age = 16 if age >= 18:     print("Tu es majeur") else:     print("Tu es mineur")

Leçon 4 — Les boucles

Une boucle répète une action plusieurs fois.

for i in range(5):     print("Tour numéro", i)
