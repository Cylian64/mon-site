✨ Apprends Linux et Python facilement

⚡ Étape 1 — Créer la clé USB

Télécharge Ubuntu sur ubuntu.com puis ouvre le Créateur de disque de démarrage.

Sélectionne le fichier ISO, sélectionne ta clé USB et clique sur Créer. Attends 10-15 minutes.

🔧 Étape 2 — Démarrer sur la clé

Branche la clé USB, allume le PC et appuie rapidement sur F2 pour le BIOS.

Va dans Security, désactive le Secure Boot, sauvegarde avec F10 et redémarre.

🚀 Étape 3 — Installer Ubuntu

Clique sur Install Ubuntu → Interactive → Default, coche les deux cases, choisis Erase disk et suis les étapes.

⏱️ L'installation dure 15-20 minutes puis le PC redémarre !

🐍 C'est quoi Python ?

Python est le langage numéro 1 pour débuter. Utilisé par les hackers, les devs IA, et les ingénieurs du monde entier.

Leçon 1 — print()

Affiche du texte à l'écran.

print("Bonjour !")

Leçon 2 — Variables

Une variable stocke une valeur.

nom = "Cylian" age = 16 print("Je m'appelle", nom)

Leçon 3 — if / else

age = 16 if age >= 18:     print("Majeur") else:     print("Mineur")

Leçon 4 — Boucles

for i in range(5):     print("Tour", i)
